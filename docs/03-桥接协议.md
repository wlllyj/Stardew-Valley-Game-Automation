# 03 · 桥接协议 v1（Mod ↔ 脑）

> **状态**：`draft-1`（2026-10-11，P2 里程碑 A）
> **定位**：这是**唯一的契约来源**。C# 侧与 Python 侧都必须按本文实现；字段名逐字一致。
> **教训来源**：旧方案（`_legacy-audit.md` §5 缺陷 D5）"schema 声明了却从不校验、C# 写 `/1` 而 Python 写 `/2`、白名单两份硬编码"。本协议要求两侧**都做版本校验**，不匹配必须报错而不是静默继续。

---

## 1. 传输层

| 项 | 约定 |
|---|---|
| 监听 | `127.0.0.1`，仅本机 |
| 端口 | 首选 `17890`，占用则依次 `17891..17900`，再失败用系统分配的空闲端口 |
| 协议 | 手写极简 HTTP/1.1（`TcpListener`）。**不用 `HttpListener`**——它对 URL 前缀有 ACL/管理员要求，会给无人值守部署带来不确定性 |
| 编码 | 请求与响应正文均为 UTF-8 JSON |
| 响应头 | `Content-Type: application/json; charset=utf-8`、`Content-Length`、`Connection: close` |
| 鉴权 | 除 `GET /v1/health` 外，所有请求必须带 `X-Auth-Token: <token>` |

**线程纪律（不可违反）**：网络线程**绝不**直接访问任何游戏对象。所有需要读游戏状态的请求入队，由 `UpdateTicked`（主线程）排空执行，结果经 `TaskCompletionSource` 交回网络线程。每次 tick 最多处理 1~2 个请求。

## 2. 服务发现

Mod 启动后写 `%APPDATA%\StardewValley\AgentFarm\bridge.json`（原子写：先写临时文件再 `File.Move` 覆盖），退出时删除。

```json
{
  "schema": "agentfarm-bridge/1",
  "port": 17890,
  "token": "3f2a…（32 位随机十六进制）",
  "pid": 12345,
  "modVersion": "0.1.0",
  "gameVersion": "1.6.15",
  "smapiVersion": "4.5.2",
  "startedAt": "2026-10-11T17:00:00+07:00"
}
```

## 3. 错误约定（所有接口通用）

除成功外，`ok` 恒为 `false`，且**必须**给出中文 `reason`：

```json
{"ok": false, "status": "unauthorized", "reason": "令牌不匹配"}
```

| status | 含义 |
|---|---|
| `ok` | 成功 |
| `no_save` | 尚未加载存档（标题界面） |
| `unauthorized` | 令牌缺失或不匹配（HTTP 401） |
| `not_found` | 路径不存在（HTTP 404） |
| `not_implemented` | 该技能尚未实现 |
| `unknown_skill` | 技能名未知 |
| `precondition_failed` | 前置条件不满足（含"目标不在当前地点"） |
| `unreachable` | 寻路无法到达 |
| `blocked` | 被物体/碰撞阻挡 |
| `timeout` | 超时 |
| `stale` | 决策依据的世界已过期（`based_on_seq` 过旧） |
| `ui_modal` | 被菜单/对话/过场挡住 |
| `busy` | 已有 exec 在执行 |
| `error` | 内部异常（附摘要） |

## 4. `GET /v1/health`

无需令牌。用于脑的存活探测与版本校验。

```json
{
  "ok": true, "status": "ok", "schema": "agentfarm-bridge/1", "modVersion": "0.1.0",
  "game": { "version": "1.6.15", "smapi": "4.5.2" },
  "runtime": { "ticks": 123, "uptimeSeconds": 12.3, "worldSeq": 4,
               "hasSaveLoaded": true, "onTitleScreen": false },
  "server": { "port": 17890, "requestsServed": 7 }
}
```

## 5. `GET /v1/observe?detail=summary|full`

未加载存档时：`{"ok":true,"status":"no_save","schema":"agentfarm-world/1","hasSaveLoaded":false}`，其余段为 `null`。

```json
{
  "ok": true, "status": "ok", "schema": "agentfarm-world/1",
  "worldSeq": 42, "generatedAt": "2026-10-11T17:00:00+07:00", "hasSaveLoaded": true,
  "clock":  { "year": 1, "season": "spring", "day": 3, "timeOfDay": 1230, "weather": "rain" },
  "player": { "name": "Jay", "location": "FarmHouse", "tile": [2, 11], "facing": 0,
              "stamina": 268.0, "maxStamina": 270.0, "health": 100, "maxHealth": 100,
              "money": 482, "farmingLevel": 0, "inventoryCount": 12,
              "tools": { "hoe": true, "axe": true, "pickaxe": true,
                         "wateringCan": true, "fishingRod": false, "weapon": true } },
  "location": { "name": "FarmHouse", "isFarm": false, "isFarmhouse": true, "isOutdoors": false,
                "objects": 1, "debris": 0, "terrainFeatures": 1, "characters": 0 },
  "farm": { "loaded": true, "hoeDirt": 0, "emptyDirt": 0, "crops": 0, "ripeCrops": 0,
            "unwateredCrops": 0, "weeds": 443, "stones": 241, "twigs": 114, "trees": 148,
            "grass": 458, "sprinklers": 0, "machinesTotal": 0, "machinesReady": 0, "animals": 0 },
  "ui": { "activeMenu": null, "isModal": false, "eventUp": false, "dialogsOnScreen": 0 },
  "liveness": { "worldAdvancing": true, "secondsSinceClockMoved": 7.3 }
}
```

**语义要点**
- `worldSeq`：单调递增。状态指纹（地点名 + 玩家坐标 + 游戏内分钟 + 金钱 + 背包数）变化时 +1。
- `liveness.worldAdvancing`：游戏内时钟在最近 N 秒内推进过。**无人值守的命脉**——它把"世界冻结"与"程序卡住"区分开（旧方案正是分不清这两件事而空转 40 分钟）。
- `detail=summary` **不得**包含全量地块；`detail=full` 可含 `farm.tiles`。
- 农场统计必须能承受 1400+ 格且**不能每帧全量扫描**。

## 6. `POST /v1/exec`

```json
{ "skill": "move_to", "args": { "tile": [64, 15] }, "timeout_ms": 8000, "based_on_seq": 42 }
```

```json
{ "ok": true, "status": "ok", "skill": "move_to", "reason": "",
  "elapsedMs": 3210, "worldSeqBefore": 42, "worldSeqAfter": 57 }
```

- `timeout_ms` 夹到 `[500, 30000]`，缺省 `8000`。
- 一次只允许一个 exec 在跑；否则 `busy`。
- `based_on_seq` 过旧时可返回 `stale`（阈值由实现定，写进注释）；脑收到 `stale` **必须重新观测后重算，禁止盲目重发**。

### 里程碑 A 的技能

| skill | args | 说明 |
|---|---|---|
| `noop` | 无 | 立即返回 `ok`，**不碰游戏**。用于验证通信链路 |
| `move_to` | `{"tile":[x,y]}` | 用游戏自带 `PathFindController` 走到目标格 |

`move_to` 规则：
1. 目标格不在当前地点 → `precondition_failed`（reason：「跨地点移动尚未实现」）。
2. 到达判定 = 玩家当前 tile == 目标。
3. 超时 → `timeout`，并**必须停止寻路**（`Game1.player.controller = null`），不得把玩家卡在控制器里。
4. 有活动菜单/对话/过场 → `ui_modal`。
